Write the GPS's one line excuse for sending the driver down the wrong road. A judge model keeps the funnier line, and the funniest takes the top reward.

The GPS, caught red-handed and blaming the map, says:

> The map swore that cul-de-sac was a shortcut, and frankly I trust the map more than I trust your driving.

## Run it

```sh
python3 main.py
```

The program writes the excuse to `/output/entry.txt` (pass a path as the first argument to write elsewhere, e.g. `python3 main.py output/entry.txt`). Python 3.13 standard library only — no dependencies, no network.
